# Кисловодская Онлайн-Академия искусств

```bash
npm install
npm run dev      # локальный сервер
npm run build    # сборка в dist/
```

## Структура проекта

```
online-academy/
├── pages/                  HTML-страницы. Путь папки = адрес на сайте
│   ├── index.html          /               «Академия» (главная)
│   ├── courses/            /courses/       «Курсы»
│   ├── masterclasses/      /masterclasses/ заглушка «в разработке»
│   ├── contests/           /contests/      заглушка
│   └── contacts/           /contacts/      «Связь»
│
├── src/                    Код и стили
│   ├── content/            ✏️ Тексты и данные — правьте здесь, без вёрстки
│   │   ├── site.ts             название, меню, контакты (на всех страницах)
│   │   ├── academy.ts          работы учеников, лицензии, отзывы
│   │   ├── courses.ts          каталог курсов
│   │   ├── course-programs.ts  модули и уроки курсов (блок «Подробнее»)
│   │   ├── plans.ts            форматы обучения (тарифы)
│   │   └── types.ts            общие типы
│   │
│   ├── components/         Переиспользуемые элементы интерфейса
│   │   ├── consultation/       блок «Получите консультацию» (форма + пояснение), на «Академии» и «Связи»
│   │   └── dropdown.ts         выпадающий список в стиле сайта
│   │
│   ├── layout/             Общий каркас каждой страницы
│   │   ├── bootstrap.ts        запуск: подключает стили, шапку и подвал
│   │   ├── header.ts
│   │   └── footer.ts
│   │
│   ├── pages/              Скрипты и стили конкретных страниц
│   │   ├── academy/            главная: работы учеников, лицензии, отзывы
│   │   ├── courses/            каталог, блок «Подробнее», тарифы
│   │   ├── contacts/           «Связь»: форма обратной связи
│   │   └── stub/               заготовка для разделов без макета
│   │
│   ├── styles/             Общие стили
│   │   ├── index.css           точка входа (подключает остальные)
│   │   ├── theme.css           цвета, шрифты, анимации (Tailwind @theme)
│   │   ├── base.css            основа, секции, «наклейки», карточки
│   │   ├── ui.css              кнопки, фильтры-«таблетки», выпадающий список
│   │   ├── header.css
│   │   └── footer.css
│   │
│   └── utils/              Вспомогательные функции (DOM, форматирование, появление при прокрутке)
│
├── public/                 Файлы «как есть»: icons/, images/ → /icons/…, /images/…
└── design/                 Макеты (в сборку не попадают)
```

## Как добавить страницу

1. Создайте `pages/<имя>/index.html` (можно скопировать `pages/contacts/index.html`).
2. Добавьте `<имя>` в список `pages` в `vite.config.ts`.
3. Добавьте пункт меню в `src/content/site.ts`.
4. Если у страницы свой код — создайте `src/pages/<имя>/<имя>.ts` и подключите его в HTML:
   `<script type="module" src="/src/pages/<имя>/<имя>.ts"></script>`.
